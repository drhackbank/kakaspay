ICICI Bank API — How live calls work

Enter your OAuth Bearer Token and Client ID in any module's Params tab then click Send Request to fire a live call to apigw.icicibank.com.

No token → sandbox mock (safe testing). Valid token → real transaction. CORS is handled when deployed on GitHub Pages.

IMPS — Immediate Payment Service

POST · Instant 24x7 fund transfer · Up to ₹5 lakh per transaction

NEFT — National Electronic Funds Transfer

POST · Batch-based · Settled in half-hourly cycles during banking hours

RTGS — Real Time Gross Settlement

POST · High-value transfers ₹2 lakh and above · Real-time settlement during banking hours
